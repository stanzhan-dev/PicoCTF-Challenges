# picoCTF Cryptography Challenges

Welcome to the **Cryptography** section of my picoCTF repository.  
This folder contains my solutions, notes, and explanations for cryptography-related challenges from **picoCTF**.

---

## About picoCTF Cryptography

picoCTF cryptography challenges are designed to teach core crypto concepts through hands-on problems. These challenges often focus on understanding how encryption, encoding, and hashing work—and how mistakes in cryptography can be exploited.

Topics commonly include:

- Classical ciphers (Caesar, Vigenère, substitution)
- Encoding and decoding (Base64, Hex, Binary)
- Hashing (MD5, SHA family)
- RSA and basic public-key cryptography
- Weak or misused cryptographic implementations

## How I Solve Crypto Challenges

1. Read the challenge carefully and identify the crypto type  
2. Analyze the weakness or mistake in the cryptography  
3. Use tools or scripts to decode, decrypt, or compute the solution  
4. Verify the flag and document the solution
